# 3D → 도트 스프라이트 변환기

3D 모델과 모션(애니메이션)을 불러오면 **N방향 × M프레임 픽셀 아트 스프라이트 시트**로 변환해 주는 브라우저 편집기입니다.
모델의 **체형 비율을 7등신 → 2~3등신 SD(치비)로 바꾸는 기능**이 있어, 같은 모델과 모션으로 SD 캐릭터 스프라이트를 만들 수 있습니다.
HD 이미지(일러스트·HD 스프라이트·프레임 시트·GIF)를 저해상도 도트로 줄이는 **이미지 → 도트 모드**도 있습니다.
서버 없이 브라우저에서만 동작합니다 (Three.js + Vite + TypeScript).

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성 (아무 정적 호스팅에 올리면 됩니다)
```

## Windows 실행 파일 (Rust)

`release/windows-x64/` 에 미리 빌드된 `sprite3d2d.exe` 가 들어 있습니다 (`windows-x64.zip` 도 동일).

- 구성: Rust + [wry](https://github.com/tauri-apps/wry)/[tao](https://github.com/tauri-apps/tao) 로 만든 얇은 셸이 WebView2 안에서 웹 앱(`dist/`)을 실행합니다. 웹 앱은 exe 안에 내장되어 있어 인터넷/서버가 필요 없습니다.
- **`sprite3d2d.exe` 와 `WebView2Loader.dll` 을 같은 폴더에 두세요.** Edge WebView2 런타임이 필요합니다 (Windows 11 / 최신 Windows 10 은 기본 설치).
- 내보내기 파일은 "다운로드" 폴더에 저장됩니다.
- 다시 빌드 (Linux, mingw-w64 필요): `./desktop/build-windows.sh`
- 아이콘은 `desktop/make-icon.py`(Pillow)로 생성합니다 (`desktop/icon/`).

## 사용법

1. **모델 열기** (또는 창에 파일 드래그&드롭): `.glb` `.gltf` `.fbx` `.obj` `.pmx` `.pmd`
   - `.gltf` 는 `.bin`/텍스처 파일을 **함께 선택**하세요.
   - **MMD(PMX/PMD)**: 텍스처가 보이도록 **"폴더 열기"** 로 모델 폴더째 불러오거나, 폴더를 창에 드롭하세요. 텍스처는 하위 폴더 구조와 무관하게 파일 이름으로 찾습니다. zip 은 풀어서 사용하세요.
2. **모션 추가**: 모션만 들어 있는 `.fbx`/`.glb` (예: Mixamo "Without Skin") 또는 MMD 모델용 **`.vmd`** 를 추가하면 클립 목록에 합쳐집니다.
   - VMD 는 현재 불러온 PMX/PMD 모델의 본 이름(センター, 上半身 …)에 맞춰 변환됩니다. 모델을 바꾸면 VMD 를 다시 추가하세요.
   - 모델과 VMD 를 한꺼번에 선택/드롭해도 됩니다.
   - 본 이름으로 연결하며 `mixamorig:` 접두어 차이는 자동으로 맞춥니다. 모델과 같은 리그의 모션이어야 합니다.
   - 트랙 매칭 수가 낮으면 경고가 표시됩니다.
3. 오른쪽 **도트 미리보기**와 아래 **타임라인**을 보면서 해상도·방향·FPS·팔레트 등을 조절합니다.
   - 미리보기 상단에서 **선택한 방향 / 전체 방향** 보기(전체 방향에서는 타일을 클릭해 방향 선택)와 배경색(체크무늬/어두운/밝은/크로마키 초록/마젠타)을 고를 수 있습니다.
   - 3D 뷰 상단의 **3/4 · 정면 · 스프라이트 시점** 버튼으로 스프라이트 카메라와 같은 각도로 확인할 수 있습니다.
   - 설정은 자동 저장되어 다음 실행 때 복원됩니다. 패널 맨 아래 **설정**에서 기본값 복원, 설정 파일(.json) 저장/불러오기가 가능합니다.
4. **내보내기**: 스프라이트 시트 PNG + JSON, 방향별 GIF, 프레임별 PNG(zip, 방향별 폴더), 현재 프레임 PNG.

파일이 없어도 **샘플 캐릭터**(박스 캐릭터 + Idle/Walk/Run/Attack)로 바로 시험해 볼 수 있습니다.

## SD(치비) 비율: 7등신 → 2~3등신

패널의 **SD 비율** 섹션에서 "SD 비율 적용"을 켜고 프리셋(4등신 / 3등신 / 2.5등신 / 2등신)을 고르거나 머리·몸통·팔·다리 크기를 직접 조절합니다. 3D 뷰와 도트 결과에 같이 반영되며, 같은 모션이 그대로 재생됩니다.

- **부위 인식**: 본 이름으로 머리/몸통/팔/다리를 자동 인식합니다. Mixamo(`mixamorig…`), MMD(頭·上半身·腕·足·ひざ… 와 D 본), Blender(`.L/.R`), 3ds Max 바이페드, 일반 이름(Head/Spine/Arm/Leg …)을 지원하고, 인식된 본 개수를 패널에 표시합니다. 손가락·머리카락·액세서리처럼 부위에 딸린 본은 부모를 따라갑니다.
- **방식**: 부위별 "누적 배율"을 목표로 본의 로컬 스케일을 정합니다 (예: 몸통 ×0.7, 머리 ×1.9 → 머리 본은 1.9/0.7 로 설정). 그래서 부위별 크기를 서로 독립적으로 지정할 수 있습니다. 부위는 균일 스케일이라 팔다리가 짧아지며 가늘어집니다.
- **바닥 맞춤**: 다리가 짧아지면 발이 뜨므로 모션 전체에서 가장 낮은 지점이 바닥에 오도록 자동으로 내립니다. 걷기·달리기에서 발 위치가 프레임마다 일정하게 유지됩니다.
- **MMD**: 센터(엉덩이) 높이와 발 IK 목표(높이·보폭)도 다리 비율만큼 줄여, IK 가 다리를 뻗지 않고 자연스럽게 접히게 합니다.
- 등신 수 표시는 7등신(머리 1 : 몸통 2.5 : 다리 3.5)을 기준으로 한 근사값입니다.

## 이미지 → 도트 (HD → SD 해상도 변환)

패널의 **입력 소스**를 "HD 이미지 → SD 도트"로 바꾸거나, 모델 없이 이미지 파일만 열거나 창에 놓으면 이미지 모드로 들어갑니다. 3D 모드와 같은 팔레트·디더·외곽선·색 보정과 같은 내보내기(시트 PNG + JSON, GIF, zip)를 그대로 씁니다.

- **입력**: 이미지 한 장(시트로 자를 수 있음), 여러 장(파일 이름 숫자 순서의 프레임), 애니메이션 GIF/WebP(프레임별 디코딩).
- **시트 자르기**: 한 장일 때 가로 칸 = 프레임, 세로 칸 = 방향(행). 내보낸 시트도 같은 배치입니다. 방향 이름은 `row1, row2 …`.
- **축소 방식**: 영역 평균(부드러움) / 최빈색(또렷함, 일러스트에 추천 — 경계가 번지지 않고 색이 늘어나지 않음) / 최근접.
- **자르기·배치**: 모든 프레임의 불투명 영역 합집합으로 한 번만 자르므로 프레임 간 크기와 위치가 흔들리지 않습니다 (원본 뷰의 점선). 비율 유지(전체/꽉 채우기)/늘이기, 아래 가운데/가운데 정렬, 여백(px), "소스 비율에 맞춰 세로 크기 계산" 버튼.
- **배경 제거**: 좌상단 색 기준, 허용 오차(%)로 가장자리와 이어진 영역을 투명으로 만듭니다. 안티에일리어싱으로 배경색이 섞인 후광은 "가장자리 정리(px)"로 벗기고, 목 틈·팔 사이 같은 고립된 배경 조각은 "내부 배경도 제거"로 지웁니다(같은 색의 전경도 지워질 수 있어 기본은 꺼짐).
- 알파 임계값(도트 스타일)으로 경계를 0/255 로 이진화하므로 반투명 가장자리는 남지 않습니다.

## 변환 방식

```
3D 씬 ─▶ 직교 카메라로 W×H 에 직접 렌더(안티에일리어싱 없음)
      ─▶ 알파 이진화 ─▶ 채도/대비/밝기 ─▶ 팔레트 양자화(+Bayer 디더) ─▶ 외곽선
```

- **카메라 고정**: 모션 전체에서 모델이 차지하는 영역을 구해 카메라를 한 번만 맞춥니다. 프레임/방향 간 크기와 발 위치가 흔들리지 않습니다.
- **방향**: 모델을 Y축으로 회전하고 조명은 카메라 기준으로 고정합니다. 0번이 정면(S)이며 S → SE → E → NE → N → NW → W → SW 순서(시계 방향)입니다.
- **제자리 모션**: 루트(Hips/Root/Pelvis) 의 X·Z 이동을 고정합니다. 걷기/달리기 모션을 스프라이트로 만들 때 켜 두세요.
- **셰이딩**: 툰 셰이딩(음영 단계 2~6)이 기본입니다. 원본 재질도 선택할 수 있습니다.
- **팔레트**: 자동 추출(메디안 컷, 모든 프레임에서 한 번만 추출해 프레임 간 색이 일관됨), PICO-8, Game Boy, Sweetie 16, 직접 입력, 제한 없음.

## 출력 형식

- 시트 PNG: **행 = 방향, 열 = 프레임**.
- JSON: Aseprite/TexturePacker(hash) 호환 — `frames`, `meta.frameTags`(방향별 `클립_방향` 태그), `meta.directions`, `meta.fps`. Phaser, Godot 임포터 등에서 바로 쓸 수 있습니다.
- GIF: 투명 배경, 현재 선택한 방향.
- 출력 배율(×1~×8)은 최근접 이웃으로 확대합니다.
- 시트 간격(0~16px): 프레임 둘레에 투명 여백을 넣어 텍스처 필터링 시 이웃 프레임 색이 번지는 것을 막습니다. JSON 의 `frame` 좌표와 `meta.padding` 에 반영됩니다.

## 단축키

`Space` 재생/정지 · `←` `→` 프레임 이동

## 알려진 한계 / 다음 단계

- 모션 리타게팅은 **본 이름 매칭**만 지원합니다 (서로 다른 리그 간 리타게팅은 미지원).
- MMD: IK/부여(회전 연동)와 모프는 지원하지만 **물리(머리카락·치마 흔들림)** 와 외곽선 셰이더, VMD 카메라/모프 외 효과는 지원하지 않습니다. 제자리 모션은 センター/全ての親 의 이동만 고정하므로, 발 IK 로 이동하는 걷기 모션은 발이 미끄러질 수 있습니다.
- MMD 지원은 실제 모델이 아닌 직접 만든 최소 PMX/VMD(일본어 본 이름, 서브폴더 텍스처)로만 검증했습니다. IK 가 많은 실제 모델에서 문제가 있으면 알려 주세요.
- 외곽선은 바깥 윤곽만 지원합니다 (내부 경계선 없음).
- SD 비율: 본이 없는 정적 메시(OBJ 등)에는 적용되지 않습니다. 팔다리 두께를 따로 유지하는 옵션은 없고(균일 스케일), 눈·입처럼 얼굴 형태를 바꾸는 모프/메시 수정은 하지 않습니다. MMD 의 발 IK 보정은 IK 가 있는 실제 모델로 검증하지 못했습니다.
- 트림/패킹, 여러 모션을 한 시트로 합치기, 모델/모션을 포함한 프로젝트 저장은 아직 없습니다 (설정만 저장됩니다).
