# 리타깃 툴 (retarget-tool)

모델(타깃)과 모션(소스)을 넣으면 모션의 본을 모델의 본에 자동으로 대응시키고, 모션을 모델에 맞게 리타깃해 미리보기 후 **GLB** 로 내보내는 독립 앱입니다.
루트 앱(`../src`)과 코드를 공유하지 않습니다 (필요한 코드는 복사했습니다). 네트워크/CDN 을 쓰지 않습니다.

## 실행

```bash
cd retarget-tool
npm install
npm run dev       # 개발 서버 (http://localhost:5173)
npm run build     # 타입 검사(tsc --noEmit) + dist/ 생성
npm run preview   # dist/ 미리보기
```

`dist/index.html` 을 브라우저에서 `file://` 로 직접 열어도 동작합니다 (단일 스크립트 번들).
`node_modules/` 와 `dist/` 는 git 에서 제외됩니다.

## 사용법

1. **① 모델 (타깃)**: `.glb .gltf .fbx .pmx .pmd` 를 놓거나 클릭. glTF 의 `.bin`, 텍스처 등 부속 파일은 함께 선택합니다.
2. **② 모션 (소스)**: `.glb .gltf .fbx .vmd` 를 놓거나 클릭. 클립이 여러 개면 드롭다운에서 고릅니다.
   - 캔버스에 파일을 놓으면 `.vmd` 는 모션, 모델이 아직 없으면 모델, 그 밖에는 모션으로 들어갑니다.
3. 둘 다 있으면 **오른쪽 표**에 본 대응이 자동으로 만들어집니다.
   - 행마다 `사용` 체크, 소스/타깃 본 선택, 신뢰도 배지(높음/보통/낮음/수동/미매핑)를 볼 수 있습니다.
   - 빨간 행은 한쪽이 비어 있는 미매핑 행입니다. 직접 선택하면 `수동` 으로 바뀝니다.
   - `자동 매핑 다시` 로 자동 결과를 되돌리고, `+ 행 추가` 로 사용자 지정 행을 더할 수 있습니다.
4. **③ 옵션**
   - 제자리 (in-place): 엉덩이의 X/Z 이동을 없앱니다 (Y 바운스는 유지).
   - 레스트 포즈 방향 보정: 두 모델의 기본 자세(T-포즈 등) 차이를 보정합니다. 자세가 이상하면 끄고 비교해 보세요.
   - 소스 방향 회전: 모션 모델이 정면을 다른 방향으로 보고 있을 때 0/90/180/270도로 맞춥니다.
   - 엉덩이 이동 배율: 비워 두면 다리 길이 비로 자동 계산합니다 (빈칸 placeholder 에 자동값 표시).
   - 샘플 FPS: 결과 클립의 샘플링 간격 (기본 30).
5. 하단 재생바에서 재생/일시정지, 스크럽, 속도(0.25~2배), 반복, 소스 표시/소스 뼈대 토글을 쓸 수 있습니다.
6. **GLB 내보내기**: 결과 클립 1개가 들어간 타깃 모델을 `모델이름_클립이름.glb` 로 저장합니다.
7. **매핑 저장 / 매핑 불러오기**: 본 대응과 옵션을 JSON 으로 저장하고 다시 씁니다. 다른 모델에 불러오면 없는 본은 경고와 함께 비워집니다.

## 자동 대응 규칙 (요약)

- 본 이름은 전각/반각 정규화 후 좌우(`左/右`, `Left/Right`, `.L/_R`, `L_` 등), 흔한 접두어(`mixamorig:`, `J_Bip_`, `Bip01`, `DEF-` 등)를 제거해 비교합니다.
- IK, 트위스트, 롤, 캔슬, 끝 본(end/tip), 더미, 폴 등은 대응 대상에서 제외합니다.
- 손가락은 엄지/검지/중지/약지/새끼 + 마디(단어 또는 숫자)로 분해합니다.
- 캐노니컬 키는 52개입니다 (중앙 6 + 좌/우 몸통 8씩 + 좌/우 손가락 15씩).

## 리타깃 방식

본의 회전 **델타**를 월드 공간에서 계산해 타깃 본에 적용합니다 (`D = Qs(t)·Qs0⁻¹`, `want = D·A·Qt0`).
그래서 축 방향, 본 계층 차이(중간 척추 개수 등), 단위(cm/m)가 달라도 대응됩니다. 엉덩이 위치는 다리 길이 비로 스케일합니다.

## 알려진 한계

- **VMD 의 IK 모션(足ＩＫ 등)은 지원하지 않습니다.** IK 키는 무시되며, 다리가 기본 자세로 남을 수 있습니다 (경고가 표시됩니다).
- VMD 보간은 베지어를 무시하고 선형으로 처리합니다.
- MMD(PMX/PMD) 타깃은 IK/물리 없이 FK 로만 보입니다. MMD 재질은 GLB 내보내기 시 경고가 날 수 있으며, 그대로 내보냅니다 (콘솔 경고).
- VMD 를 쓸 때 소스 스켈레톤은 내장 표준 MMD 스켈레톤(손가락은 펼침 없는 단순 체인)입니다. 모션은 본 이름 기준이므로 MMD 가 아닌 본 이름에는 적용되지 않습니다.
- 소스와 타깃의 정면 방향이 다르면 "소스 방향 회전"으로 직접 맞춰야 합니다 (자동 판별하지 않습니다).
- 본 이름이 모호하면 (예: 이름에 `L` 한 글자만 있는 경우) 자동 대응이 틀릴 수 있습니다. 표에서 확인해 주세요.
- 결과는 본 회전 키와 (몸통 본에 한해) 위치 키로 구성된 `_retarget` 클립 1개입니다. 원본 모델의 기존 클립은 포함되지 않습니다.
- 메시 없이 본만 있는 모델은 본 뼈대만 보입니다.
