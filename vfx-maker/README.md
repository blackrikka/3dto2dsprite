# VFX 메이커

도트(픽셀 아트) **파티클 이펙트**를 만들어 **스프라이트 시트 / GIF** 로 내보내는 편집기입니다.
(3D 모델 → 도트 변환기와는 별개의 앱입니다. 서버 없이 브라우저/Windows 앱에서 동작합니다.)

## 실행

```bash
cd vfx-maker
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 정적 파일
```

### Windows 설치/실행
- **설치**: `release/VFXMaker-Setup.exe` (관리자 권한 불필요, 사용자 폴더 `%LOCALAPPDATA%\Programs\VFXMaker`, 시작 메뉴/바탕화면 바로가기, 앱 제거 등록, 무인 설치 `/S`).
- **설치 없이**: `release/windows-x64/` 의 `vfxmaker.exe` + `WebView2Loader.dll` 을 같은 폴더에 두고 실행. Edge WebView2 런타임 필요 (Windows 11/최신 10 은 기본 설치).
- 내보낸 파일은 "다운로드" 폴더에 저장됩니다.
- 다시 빌드 (Linux, `mingw-w64`·`nsis` 필요): `./desktop/build-windows.sh && ./desktop/build-installer.sh`

## 사용법

1. **이펙트 → 프리셋 불러오기**에서 시작하거나(모닥불, 폭발, 타격 스파크, 슬래시, 연기, 마법 차징, 힐링, 눈, 비, 반짝임, 물 튀김) "새 이펙트"로 처음부터 만듭니다.
2. **이미터(레이어)** 를 추가/복제/순서 변경/켜고 끄기. 위쪽 이미터가 먼저(아래쪽에) 그려집니다. 미리보기를 **드래그하면 선택한 이미터가 이동**합니다 (가이드가 이미터의 위치와 발생 모양을 보여 줍니다).
3. 속성을 조절하면 미리보기와 아래 프레임 스트립이 바로 갱신됩니다. `Space` 재생/정지, `←` `→` 프레임 이동.
4. **도트 후처리**(반투명 처리, 팔레트, 외곽선)를 정하고 **내보내기**.

## 이미터 속성

| 구분 | 내용 |
|---|---|
| 발생 | 지속(초당 N개) / 한 번에(N개), 시작 시각, 시간 폭 |
| 위치·모양 | 점·원·원 테두리·호·선·사각형, 크기/각도/회전, **순서대로 배치**(슬래시·빔·링 확장) |
| 움직임 | 방향(고정 각도/바깥/안쪽/접선), 퍼짐, 속도, 중력 X·Y, 저항, 흔들림, 수명 |
| 입자 | 네모·원·빛·마름모·십자·별·링·꼬리, 크기 시작→끝(+무작위), 합성(가산/일반), 서서히 나타남/사라짐, **색 그라디언트(최대 8지점, 지점별 불투명도)** |

## 설계: 시뮬레이션하지 않고 시간 T 에서의 상태를 직접 계산

입자는 인덱스 `i` 의 해시(시드)로 발생 시각·위치·속도·수명이 정해지고, 위치는 중력/저항을 포함한 **닫힌 형태의 운동 방정식**으로 계산합니다. 그래서

- 타임라인을 **임의로 스크럽**해도, 어느 프레임을 내보내도 결과가 정확히 같습니다 (같은 시드 = 같은 모양).
- **루프**를 켜면 입자 나이를 `길이` 로 감싸서 계산하므로 마지막 프레임과 첫 프레임이 **끊김 없이** 이어집니다. 루프 프리셋 7종 모두 T=0 과 T=길이의 프레임이 픽셀 단위로 동일함을 검증했습니다. (루프에서는 입자 수명이 이펙트 길이를 넘지 않게 제한됩니다.)

## 도트 후처리

- **반투명 처리**: 디더(8×8 Bayer 로 투명도를 성기게 표현, 연기·빛에 적합) / 이진화(임계값, 타격·슬래시처럼 선명한 이펙트) / 그대로.
- **팔레트**: 자동 추출(모든 프레임에서 한 번만 추출해 프레임 간 색 일관) / PICO-8 / Game Boy / Sweetie 16 / 직접 입력 / 제한 없음. 외곽선 옵션.
- 렌더는 지정한 해상도(예: 128×128)에서 안티에일리어싱 없이 정수 픽셀로 그립니다.

## 내보내기

- **시트 PNG + JSON**: 열 수(0=한 줄)와 프레임 간격(패딩) 지정. JSON 은 Aseprite/TexturePacker(hash) 호환이며 `frameTags`, `fps`, `loop` 포함.
- **GIF**: 투명 배경, 루프 설정 반영. **프레임 PNG(zip)**, **현재 프레임 PNG**. 출력 배율 ×1~×8 (최근접 이웃).
- 이펙트는 `.vfx.json` 으로 저장/불러오기, 작업 내용은 자동 저장됩니다.

## 한계

- 서브 이미터(입자 소멸 시 다른 입자 발생), 충돌, 텍스처/스프라이트 입자, 트레일 잔상(꼬리 모양은 가능), 3D 이펙트는 없습니다.
