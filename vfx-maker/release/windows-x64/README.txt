 - 내보내기한 파일(PNG/JSON/GIF/zip)은 "다운로드" 폴더에 저장됩니다.

설치해서 쓰려면 상위 폴더의 VFXMaker-Setup.exe 를 실행하세요 (시작 메뉴 등록, 제거 프로그램 포함).
